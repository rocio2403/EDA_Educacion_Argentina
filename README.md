# EDA Educación Argentina

## Objetivo

El objetivo de este proyecto es realizar un análisis exploratorio
de datos (EDA) sobre información educativa en Argentina, con el fin
de comprender la distribución de las unidades educativas y la
matrícula por distrito.

## Descripción del proyecto

El análisis se basa en datos públicos educativos organizados en
múltiples archivos, los cuales son explorados, limpiados y
relacionados para obtener una visión general del sistema educativo.

## Tecnologías utilizadas

- Python
- pandas
- matplotlib
- SQLite
- Jupyter Notebook
- Power BI

## Estructura del repositorio

- `data/`: datos crudos y procesados  
- `notebooks/`: análisis exploratorio  
- `outputs/`: gráficos y resultados  
- `src/`: funciones auxiliares (opcional)

## Estado del proyecto

Proyecto en desarrollo. El análisis se encuentra en etapa de
exploración y limpieza de datos.
